# Secure Field

<Lead>Enter a password, and show it when you need to read it.</Lead>

<Demo name="secure-field/basic" />

## When to use it

Use a secure field for passwords, PINs and recovery keys. It looks like a [Text Field](/docs/components/text-field) but shows dots, offers the right password to password managers and hides the text again when its form submits.

Set `autoComplete="current-password"` when signing in and `"new-password"` when creating or changing one. Keep the show button unless the value is a PIN typed on a shared screen.

## Usage

```tsx
import { SecureField, SecureFieldInput, SecureFieldToggle } from "@dreambase/stardust/secure-field"
```

Form options (`name`, `required`, `disabled`, `readOnly`, `autoComplete`, `value`) go on `SecureField`. `placeholder`, `id`, `autoFocus` and ARIA names go to the input. Pass children to lay out `SecureFieldInput` and `SecureFieldToggle` yourself.

### Shown at first and no toggle

`defaultVisible` starts with the text shown, for something people read aloud or copy, like a Wi-Fi password. `toggle={false}` leaves the eye button out.

## Platform behavior

- **macOS.** The bordered text field. The eye sits at the trailing edge in secondary gray and turns accent while the password shows. While Caps Lock is on and the field is focused, a ⇪ appears beside it, as in the macOS login window.
- **iPadOS and iOS.** The filled gray field at 44 points, with a 17-point eye that keeps a 44-point touch target.
- **Every platform.** Dots are spaced slightly wider than letters, and the caret stays where it was when the password is shown or hidden.

## Accessibility

- The toggle is a real button with `aria-pressed`, named "Show password". Rename it with `toggleLabel`, like "Show recovery key".
- The toggle is `type="button"`, so Return in the field still submits the form.
- The text is hidden again when the form submits or the page is hidden, so it isn't left on screen.

`SecureFieldInput` takes the props of an `input`; `SecureFieldToggle` the props of a `button`, and draws eye or eye.slash unless it has children.

### Data attributes

| Attribute | On | Values |
| --- | --- | --- |
| `data-size`, `data-variant` | SecureField | As on Text Field |
| `data-visible` | Every part | Present while the text shows |
| `data-capslock` | Every part | Present while Caps Lock is on and the field is focused |
| `data-filled`, `data-disabled`, `data-readonly` | Every part | Field state |

### CSS variables

It reads the Text Field's variables: `--sd-text-field-radius`, `--sd-text-field-padding`, `--sd-text-field-font` and `--sd-text-field-icon`.
