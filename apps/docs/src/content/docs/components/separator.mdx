# Separator

<Lead>Divide groups of content with a hairline.</Lead>

<Demo name="separator/basic" />

## When to use it

Use a separator between groups that a reader should take as separate, like a profile's name and its bio, or between links in a row. Apple's separators are thin and quiet: one physical pixel in a translucent gray, so they divide without drawing the eye.

Prefer space and grouping first. Inset grouped lists, cards and sections already separate content; add a line only when space alone doesn't.

## Usage

```tsx
import { Separator, SeparatorLabel } from "macbetter/separator"
```

### Vertical

Set `orientation="vertical"` between items in a row. It stretches to the row's height.

<Demo name="separator/vertical" />

### Inset

`inset="leading"` starts the line at the row's text instead of its edge, as between the rows of an iOS list. `inset` alone insets both ends. Both use the platform's row padding; set `--mb-separator-inset` to line up with text that sits after an icon.

<Demo name="separator/inset" />

### With a label

`SeparatorLabel` puts a short word between two lines. The word carries the meaning, so the lines are hidden from screen readers.

<Demo name="separator/label" />

## Platform behavior

The line is the same hairline everywhere. Its inset follows the platform's row padding: 10 points on macOS and 16 on iOS and iPadOS, so an inset separator lines up with list text on each.

## Accessibility

- A separator is announced with the `separator` role and its orientation, so a screen reader hears the groups as separate. It never takes focus.
- Pass `decorative` when the surrounding content already shows the division; the separator gets `role="none"`.
- In Increase Contrast, the separator token darkens on its own.

### Data attributes and variables

| Attribute or variable | On | Description |
| --- | --- | --- |
| `data-orientation` | `.mb-separator` | `horizontal` or `vertical`, from ui-sdk. |
| `data-inset` | `.mb-separator` | `both` or `leading`. |
| `--mb-separator-color` | `.mb-separator` | The line's color. Defaults to `--mb-separator`. |
| `--mb-separator-inset` | `.mb-separator` | How far an inset line starts from the edge. |
