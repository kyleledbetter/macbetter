# Tabs

<Lead>Switch between related views that share the same space.</Lead>

<Demo name="tabs/basic" height={280} />

## When to use it

Use a tab view to group a few related panes of controls, like the sections of a settings window, where each pane makes sense on its own. Keep the labels to a word or two and use nouns, not verbs.

Tabs are for content within a window. To switch between the top-level areas of an iPhone or iPad app, use a [tab bar](/docs/components/tab-bar). To change how one set of content is shown, like a list or a grid, use a [segmented control](/docs/components/segmented-control) in the toolbar.

Keep the number of tabs small, usually six or fewer. If people need more, a sidebar or a pop-up button reads better.

## Usage

```tsx
import { Tabs, TabsList, TabsPanel, TabsTab } from "macbetter/tabs"
```

### Tab view

The default `bordered` variant is the macOS tab view: a segmented strip sits on the top edge of a recessed, framed box. The selected segment slides to the tab you choose.

<Demo name="tabs/basic" height={280} />

### Plain

`variant="plain"` drops the frame and the track. A soft capsule slides behind the selected label, with no underline, for tabs at the top of a page or a popover. Put decorative icons in `TabsTabIcon`.

<Demo name="tabs/plain" height={220} />

## Platform behavior

- **macOS**: a compact strip, 24px tall, centered on the panel's top edge, with hover feedback under a pointer.
- **iPadOS and iOS**: the strip stretches to the width of the content as a segmented control, 34pt tall, and the panel becomes an inset grouped surface below it. The selected segment gives a little under the finger.
- A vertical tab view (`orientation="vertical"`) puts the strip beside its panel on every platform.

## Accessibility

- The list is a `tablist`; each tab controls its panel, and each panel is labelled by its tab. Name the list with `aria-label`.
- Tab moves focus into the list at the selected tab and out again on the next Tab. Left and Right move between tabs and select them, Home and End go to the ends, and right-to-left text swaps the arrows.
- Icons in `TabsTabIcon` stay out of the tab's name. An icon-only tab still needs `aria-label`.

### Data attributes and CSS variables

| Attribute or variable | On | Meaning |
| --- | --- | --- |
| `data-variant` | `.mb-tabs` | `bordered` or `plain` |
| `data-selected` | `.mb-tabs-tab`, `.mb-tabs-panel` | The selected tab and its panel |
| `data-orientation` | every part | `horizontal` or `vertical` |
| `data-disabled` | `.mb-tabs-tab` | The tab can't be selected |
| `--mb-tabs-height` | inherited | Height of the strip: 24px on macOS, 34pt on touch |
| `--mb-tabs-padding` | inherited | Horizontal padding inside each tab |
| `--active-tab-left`, `--active-tab-width`… | `.mb-tabs-indicator` | The selected tab's box, from ui-sdk |
