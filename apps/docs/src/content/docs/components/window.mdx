# Window

## When to use it

Use a window to present a Mac app inside a web page: a product tour, a marketing screenshot that people can use, or an app that runs in the browser and should feel like it belongs on the desktop. The title bar, traffic lights and toolbar tell people at a glance what kind of app it is.

To present an iPhone or iPad layout, use a [device frame](/docs/components/device-frame).

A window isn't window management. A window doesn't move, resize or close by itself: wire the traffic lights to your own handlers if they should do something.

## Usage

```tsx
import {
  Window,
  WindowBody,
  WindowSidebar,
  WindowTitle,
  WindowTitlebar,
  WindowTrafficLights,
} from "macbetter/window"
```

### Title-only windows

A compact title bar holds the traffic lights and a centered title, like a utility window or About This Mac. Set `inactive` to draw a window behind the key window: its traffic lights turn gray and its title dims.

<Demo name="window/basic" platforms={["macos"]} wallpaper height={300} />

### Sidebar and toolbar

Put a `WindowSidebar` first and it becomes a pane of glass inset from the window's edges, spanning the full height. Place the traffic lights at its top. The title bar and body take the column beside it, and a [Toolbar](/docs/components/toolbar) in the title bar becomes the unified toolbar. A [Sidebar](/docs/components/sidebar) inside drops its own material, so glass never sits on glass.

When the window gets narrow, the toolbar's search field folds into a magnifying glass before anything else gives way, and below 540 points the sidebar hides, as a Mac window does when you drag it small.

<Demo name="window/finder" platforms={["macos"]} wallpaper height={560} />

### Window controls

Pass `onClose`, `onMinimize` or `onZoom` to `WindowTrafficLights` and each light becomes a button. Their glyphs appear when the pointer is over the group or a light has keyboard focus.

## Platform behavior

A window is a macOS idiom, and it draws the same whatever platform the page is on. Its title bar is 52 points tall when it holds a toolbar and 28 points when it only holds a title, and it keeps Apple's red, yellow and green traffic lights in every theme, because they're system chrome rather than brand color.

In a right-to-left language the window mirrors, as macOS does: the traffic lights and the sidebar move to the right edge, with Close nearest the corner.

## Accessibility

- `Window` is a group. Name it with `aria-label`, usually the app's or the document's name.
- Without handlers, the traffic lights are decorative and hidden from assistive technology. Pass `onClose`, `onMinimize` or `onZoom` and each becomes a real button named Close, Minimize or Zoom, in a group named Window controls. Their glyphs show when the pointer is over the group or a light has keyboard focus.

### Data attributes and CSS variables

| Name | On | Description |
| --- | --- | --- |
| `data-inactive` | `.mb-window` | The window is behind the key window. |
| `data-variant` | `.mb-window-titlebar` | `unified` or `compact`. |
| `data-light` | `.mb-window-traffic-light` | `close`, `minimize` or `zoom`. |
| `--mb-window-radius` | `.mb-window` | Corner radius. 16 points. |
| `--mb-window-sidebar-width` | `.mb-window` | Width of the inset sidebar. 220 points. |
| `--mb-window-titlebar-height` | `.mb-window` | Height of the unified title bar. |
| `--mb-window-sidebar-inset` | `.mb-window` | The gap between the sidebar's glass and the window's edges. 6 points. |
