# Toggle

<Lead>A button that stays pressed until you press it again, alone or in a group.</Lead>

<Demo name="toggle/basic" />

## When to use it

Use a toggle for a button whose state is part of what it shows: Bold in a formatting bar, a sidebar button in a toolbar, a favorite star. It changes something right away, like a switch, but looks like a button because it lives among buttons.

- Keep the label or icon the same in both states. The pressed fill says it's on; screen readers say "pressed".
- Group toggles that belong together in a `ToggleGroup`. With `multiple`, several can be pressed, like Bold and Italic. Without it, one at a time, like text alignment.
- For a setting in a list or form, use a [Switch](/docs/components/switch) or [Checkbox](/docs/components/checkbox). For switching views, use a [Segmented Control](/docs/components/segmented-control).

## Usage

```tsx
import { Toggle, ToggleGroup, ToggleIcon } from "macbetter/toggle"
```

Wrap icons in `ToggleIcon`, which hides them from screen readers. An icon-only toggle needs an `aria-label`.

### Group

A `ToggleGroup` has one tab stop, and the arrow keys move between its toggles. `variant="bezeled"` joins them into one raised control, like a "select any" segmented control on macOS.

<Demo name="toggle/group" />

### One at a time

Leave out `multiple` and pressing one toggle releases the others. `deselectable={false}` keeps one pressed, which suits choices like text alignment that always have a value.

<Demo name="toggle/single" />

### In a toolbar

The default `plain` variant is a toolbar button: no bezel until it's hovered or pressed. `tone="accent"` tints the pressed icon with the accent, as Xcode's panel buttons do.

<Demo name="toggle/toolbar" />

### With a label

Put text after the icon. Bare text is wrapped for you, so the toggle gets the right padding.

<Demo name="toggle/label" />

### Sizes

`size` is `sm`, `md` or `lg`. Set it on a group to size every toggle inside.

<Demo name="toggle/sizes" />

### Controlled

Pass `pressed` and `onPressedChange` to keep the state yourself. In a group, use the group's `value` and `onValueChange`, which list the pressed toggles' values.

<Demo name="toggle/controlled" />

## Platform behavior

- **macOS.** Toolbar-style: a pressed toggle sinks into a gray fill, and its icon turns from secondary to primary label color. Bezeled toggles look like push buttons and darken when on, with an inner shadow. A bezeled group draws hairline dividers between toggles.
- **iPadOS and iOS.** Capsules, and a pressed toggle is tinted with the accent: an accent-colored label on a light accent fill, in semibold. A bezeled group becomes a gray capsule with tinted capsules inside. Presses give a small, springy scale.
- **Every platform.** Toggles smaller than the touch minimum still answer presses across the full target.

## Accessibility

- Renders a native button with `aria-pressed`. Enter and Space press it.
- A group follows the toolbar keyboard pattern: Tab enters on the pressed toggle (or the first), the arrow keys move, Home and End jump to the ends. It has the `group` role, so name it with `aria-label`.
- Inside a group, a disabled toggle stays focusable with `aria-disabled`, so arrow keys still reach it.
- The pressed state is a fill, not only a color, and pressed text keeps 4.5:1 contrast on its tint.
- Bezeled edges are as soft as AppKit's; with Increase Contrast on (`prefers-contrast: more`) they darken to 3:1.

### Data attributes

| Attribute | On | Values |
| --- | --- | --- |
| `data-variant` | Toggle, ToggleGroup | `plain`, `bezeled` |
| `data-tone` | Toggle | `neutral`, `accent` |
| `data-size` | Toggle, ToggleGroup | `sm`, `md`, `lg` |
| `data-pressed` | Toggle | Present while pressed |
| `data-has-icon` | Toggle | Present when it holds a `ToggleIcon` |
| `data-orientation` | ToggleGroup | `horizontal`, `vertical` |
| `data-disabled` | Both | Present when disabled |

### CSS variables

Set these on a toggle or a group.

| Variable | Default | What it sets |
| --- | --- | --- |
| `--mb-toggle-height` | `--mb-control-height` | Height, and the width of an icon-only toggle |
| `--mb-toggle-padding` | `--mb-control-padding` | Inline padding of a labeled toggle |
| `--mb-toggle-radius` | `--mb-control-radius` | Corner radius |
| `--mb-toggle-bg-pressed` | Per platform | The pressed fill |
| `--mb-toggle-fg-pressed` | Per platform | The pressed label and icon color |
| `--mb-toggle-edge` | A soft ink hairline | The edge of a bezeled toggle or group |
