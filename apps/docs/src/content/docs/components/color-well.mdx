# Color Well

<Lead>Show a color and open an editor to change it.</Lead>

<Demo name="color-well/basic" />

## When to use it

Use a color well wherever someone picks a color for something, like a highlight, a label or a shape's fill. The well always shows the current color; pressing it opens an editor in a popover, and every change applies as it happens.

- Put the well next to a label that names what it colors.
- Offer presets that fit the context, like your brand's colors, so most people never need the full editor.
- Turn off the opacity slider with `alpha={false}` when transparency makes no sense, like for a text color.

## Usage

```tsx
import { ColorWell } from "macbetter/color-well"
```

`aria-label` names both the color picker and the well's button. The value is a CSS color string; `format="hex"` (the default) writes it as hex, with an alpha pair when it's translucent.

## Platform behavior

- **macOS.** A bezeled well, like NSColorWell, with the color inset in a rounded rectangle. It stays pressed while its popover is open. The editor floats on a translucent material: a saturation and brightness area, hue and opacity sliders, a hex field, a screen color picker where the browser supports one, and presets.
- **iPadOS and iOS.** UIColorWell's circle of color inside a spectrum ring. The editor has larger thumbs and touch targets. On an iPhone it opens as a bottom sheet; on iPad it's a popover.
- **Every platform.** Transparent colors show over a checkerboard, and thumbs stay inside their tracks at both ends.

## Accessibility

- The well is a button that opens the editor, and focus moves into it. Escape closes it and returns focus to the well.
- The area's thumb is a two-dimensional slider named for both channels, like "Saturation 76%, Brightness 96%". Each slider is a slider, with arrow keys, Shift for ten steps and Page Up and Page Down.
- Presets are a listbox, named by color, like "vivid red". The arrow keys move between them.
- The hex field accepts any CSS color when you press Enter or leave it.

### Data attributes

| Attribute | On | Values |
| --- | --- | --- |
| `data-size` | Root | `sm`, `md`, `lg` |
| `data-open` | Well | Present while the editor is open |
| `data-presentation` | Editor | `popover`, `sheet` |
| `data-starting-style`, `data-ending-style` | Editor | Present while it opens or closes |
| `data-channel` | Sliders | `hue`, `alpha` |
| `data-selected` | Presets | Present on the preset that matches the color |
| `data-out-of-gamut` | Every part | Present while a drag holds a color outside the gamut |
