# Radio

<Lead>Choose one option from a small set of mutually exclusive choices.</Lead>

## When to use it

Use radio buttons for two to about five choices where exactly one applies and people benefit from seeing them all at once, like a backup schedule. For more choices, use a [Pop-Up Button](/docs/components/select). For a choice that switches what's on screen, use a [Segmented Control](/docs/components/segmented-control). For a single on/off option, use a [Checkbox](/docs/components/checkbox).

- Start with a sensible default checked, so the group always has a value.
- Keep titles short and parallel. Put details in a description.
- On iOS, the familiar form is a list of rows with a checkmark on the chosen one. Use `variant="list"`.

## Usage

```tsx
import { Radio, RadioGroup } from "@dreambase/stardust/radio"
```

Give each `Radio` a `value` and its title as children. Name the group with `aria-label`, `aria-labelledby` or a [Field](/docs/components/field) label.

## Platform behavior

- **macOS.** A 14-point circle with a hairline edge. Checked, it fills with the accent around a dot that springs in: white on the system blue, or the theme's on-accent color, so the dot holds 3:1 on any accent.
- **iPadOS and iOS.** A larger, 22-point circle with an outlined ring, and the same accent fill and dot. The list variant uses 48-point rows, inset separators and an accent checkmark.
- **Every platform.** The hit area extends to the platform minimum, and the whole label is pressable.

## Accessibility

- The group has the `radiogroup` role and is one tab stop: Tab enters on the checked radio, and the arrow keys move and check. Space checks the focused radio.
- Each radio renders a button with the `radio` role, plus a hidden native radio for forms.
- In the list variant, the focus ring goes around the whole row.

### Data attributes

| Attribute | On | Values |
| --- | --- | --- |
| `data-variant` | RadioGroup | `default`, `list` |
| `data-checked` / `data-unchecked` | Radio, indicator | The state |
| `data-disabled`, `data-readonly`, `data-required` | Both | Present in those states |
| `data-invalid` | RadioGroup | Present while a `Field` shows the group as invalid; its unchecked radios get a red edge |
