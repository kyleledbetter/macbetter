# Stepper

<Lead>Change a number by small, fixed steps, with or without a field to type it.</Lead>

<Demo name="stepper/basic" />

## When to use it

Use a stepper for a number that people usually change by a little, like copies to print, guests at a table or a font size. It suits small ranges; for a wide range or an imprecise value, use a [Slider](/docs/components/slider).

- `NumberField` pairs a text field with the stepper, so people can type a number or step it. Use it whenever typing a value could be faster than stepping to it.
- `Stepper` is the buttons alone, for a value shown elsewhere, like "Guests: 2" in a row's title. Always show the value next to it.

## Usage

```tsx
import { NumberField, Stepper } from "macbetter/stepper"
```

Name the field with a [Field](/docs/components/field) label, `aria-label` or `aria-labelledby`. The buttons are named "Decrease" and "Increase"; change them with `decrementLabel` and `incrementLabel`.

### Stepper alone

Its number field is visually hidden but still takes focus, so keyboard and screen reader users can step it with the arrow keys. Point `aria-labelledby` at the visible value.

<Demo name="stepper/stepper" />

### Step and format

`min`, `max` and `step` set the bounds and the step. `format` takes `Intl.NumberFormat` options; for percents, the value is a fraction, so 75% is 0.75.

## Platform behavior

- **macOS.** A text field with an NSStepper beside it: a narrow, raised control split into up and down arrows. Numbers align to the trailing edge of the field. The field shows the accent focus ring whenever it has focus.
- **iPadOS and iOS.** The UIStepper capsule, with − and + separated by a hairline, beside the value. The field drops its border and reads as the value itself.
- **Every platform.** Holding a button repeats the step. A button at its bound dims and stops responding.

## Accessibility

- The field follows the spinbutton keyboard: ArrowUp and ArrowDown step, Shift steps by ten, Page Up and Page Down by the large step, Home and End go to the bounds, and Enter or leaving the field commits typed text.
- The step buttons stay out of the tab order, because the focused field gives the same steps from the keyboard. Each points at the field with `aria-controls`.
- The standalone stepper draws the focus ring around its buttons when its hidden field has focus.

### Data attributes

| Attribute | On | Values |
| --- | --- | --- |
| `data-size` | NumberField, Stepper | `sm`, `md` |
| `data-step` | Buttons | `decrement`, `increment` |
| `data-disabled` | Buttons | Present when the button can't step, including at a bound |
| `data-disabled`, `data-readonly` | Root | Present in those states |

### CSS variables

| Variable | macOS | iOS | What it sets |
| --- | --- | --- | --- |
| `--mb-stepper-width` | `15px` | `94px` | Width of the stepper |

| `--mb-stepper-height-sm` | `--mb-control-height-sm` | `28px` | Small height |
| `--mb-number-field-width` | `64px` | `5ch` | Width of the text field |
