# Slider

<Lead>Choose a value, or a range, from a continuous or stepped scale.</Lead>

## When to use it

Use a slider when the exact number matters less than the position, like volume, brightness or a price range, and when seeing the effect while dragging helps. When people need a precise number, pair the slider with a [Number Field](/docs/components/stepper) or use one instead.

- Put icons or labels at the ends that say what each end means, like a small and a large speaker.
- Fill the track from the minimum with the accent, so the value reads at a glance.
- Use tick marks only when there are a few meaningful steps, like a key repeat rate.

## Usage

```tsx
import { Slider, SliderControl, SliderValue } from "@dreambase/stardust/slider"
```

`Slider` draws its own track, fill and thumb. Name the thumb with `thumbLabel`, or put the slider in a [Field](/docs/components/field) whose label names it.

### With a label and value

Compose the parts to place a `FieldLabel` and a `SliderValue` above the track. `format` takes `Intl.NumberFormat` options and sets both the shown value and what screen readers hear.

<Demo name="slider/field" />

### Range

Pass an array for a range, and the slider draws a thumb per value with the accent fill between them. Name each thumb.

<Demo name="slider/range" />

### Tick marks

`ticks` draws marks under the track: `true` puts one at every step, or pass a count. The thumb snaps to `step`.

<Demo name="slider/ticks" />

### Vertical

`orientation="vertical"` runs the slider bottom to top, 160 points tall by default. Set a `height` to change it.

### Sizes

`size="sm"` is a smaller thumb and thinner track for inspectors.

Pass `value` and `onValueChange`, which runs on every step of a drag. Use `onValueCommit` to save once the drag ends.

## Platform behavior

- **macOS.** A thin, 4-point track and a 20-point white knob with a soft shadow. The knob dims slightly while held, as AppKit's does.
- **iPadOS and iOS.** A 6-point track and the 28-point UISlider thumb, which grows a little under the finger while you drag.
- **Every platform.** The track is inset by half a thumb, so the thumb never hangs past the ends, and the control is at least as tall as the platform's touch target. Tick marks line up with the steps they mark.

## Accessibility

- Each thumb is a native range input, so the arrow keys, Page Up and Page Down, Home and End work, and screen readers on phones adjust it with their own gestures.
- Name every thumb, with `thumbLabel`, a `FieldLabel` or `aria-label` on a `SliderThumb`. In a range, name each end.
- The focus ring goes around the thumb whose input has focus.

### SliderControl

Draws the track, the accent fill and one thumb per value when it has no children. Takes `thumbLabel` and `ticks` (a count).

### Other parts

`SliderValue` shows the formatted value. `SliderTrack`, `SliderIndicator`, `SliderThumb` and `SliderTicks` are exported for a slider you compose yourself.

### Data attributes

| Attribute | On | Values |
| --- | --- | --- |
| `data-size` | Slider | `sm`, `md` |
| `data-orientation` | Every part | `horizontal`, `vertical` |
| `data-dragging` | Every part | Present while a thumb is dragged |
| `data-index` | SliderThumb | Which value the thumb shows |
| `data-disabled` | Every part | Present when disabled |
