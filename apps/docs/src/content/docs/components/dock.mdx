# Dock

<Lead>Launch and switch between apps from a shelf of icons that grow under the pointer.</Lead>

<Demo name="dock/basic" platforms={["macos"]} wallpaper height={300} />

## When to use it

Use a dock as the launcher of a desktop-like experience: a portfolio, a product tour, or a web app that hosts several tools. Each item is an app or a place people come back to often.

Keep it to the destinations people use most, in an order that doesn't change on its own. Mark the ones that are open with the running dot, and put documents and the Trash after a separator, as macOS does. The dock is macOS chrome; on iPhone and iPad, use a [tab bar](/docs/components/tab-bar).

## Usage

```tsx
import { Dock, DockItem, DockSeparator } from "@dreambase/stardust/dock"
```

### Items, labels and the running dot

Give every `DockItem` a `label`: it's the item's accessible name and the label that appears above it on hover. Put the icon inside as its only child; the dock rounds it to the app-icon shape and sizes it. `running` draws the dot under an open app.

<Demo name="dock/basic" platforms={["macos"]} wallpaper height={300} />

### Magnification and launching

Move the pointer along the dock: icons grow with their distance from the pointer and spring back when it leaves. Set `magnification` to change how big the icon under the pointer gets, or `1` to turn it off. Clicking an item that isn't `running` bounces it while it launches. Pass `href` to make an item a link.

## Platform behavior

- **macOS**: the dock is a glass shelf. Magnification follows a mouse or trackpad pointer only, never touch, and is off under Reduce Motion.
- **iPadOS and iOS**: there's no magnification without a pointer; items keep their size and the shelf works like a toolbar of icons.
- Icons default to 48px; set `--sd-dock-icon-size` on the dock to change it.

## Accessibility

- The dock is a ui-sdk Toolbar: one tab stop, then Left and Right move between items and Home and End go to the ends. Name it with `aria-label`.
- Each item is a button, or a link with `href`, named by its `label`. The visible label is hidden from assistive technology so the name isn't read twice.
- Keyboard focus shows the accent ring and the item's label.

### DockSeparator

The line between apps and documents. Takes no props of its own.

### Data attributes and CSS variables

| Attribute or variable | On | Meaning |
| --- | --- | --- |
| `data-magnifying` | `.sd-dock` | The pointer is over the dock |
| `data-running` | `.sd-dock-item` | The app is open |
| `data-bouncing` | `.sd-dock-item` | The app is launching |
| `--sd-dock-icon-size` | `.sd-dock` | Resting icon size, 48px |
| `--sd-dock-scale` | `.sd-dock-item` | The icon's current magnification, written as the pointer moves |
