# Split View

## When to use it

Use a split view when people move through a hierarchy and want to keep their place: mailboxes, then messages, then the message itself. Each column narrows the one after it, so the leading column is the broadest and the trailing one the most specific.

Keep it to two or three columns. Let people resize the panes and collapse the ones they don't need, and give each pane a sensible minimum so nothing gets crushed. An inspector belongs on the trailing side and shows details about the selection in the content.

## Usage

```tsx
import { SplitView, SplitViewDivider, SplitViewPane } from "macbetter/split-view"
```

### Sidebar, content and detail

Put a `SplitViewDivider` between each pair of panes and name it with `aria-label`. Sizes are percentages as numbers or strings with `px`; a pane without `defaultSize` takes what's left. `variant="sidebar"` gives a pane the translucent sidebar material. Drag the mailboxes closed: the pane is `collapsible`.

<Demo name="split-view/mail" platforms={["macos", "ipados"]} wallpaper height={520} />

### Inspector

`variant="inspector"` gives the trailing pane the secondary background. Pixel bounds hold as the window resizes, so the inspector stays between 200 and 320 pixels wide.

## Platform behavior

- **macOS**: like `NSSplitView`, a 1px divider in the separator color, with a resize cursor while it's hovered or dragged.
- **iPadOS**: like `UISplitViewController`, a hairline between columns, with a 24pt touch area around it so a finger can catch it.
- Under a pointer the hit area is 10px wide; ui-sdk extends it without changing how the line looks.
- A focused or dragged divider turns the accent color so you can see which one the keys move.
- A [Sidebar](/docs/components/sidebar) inside a `variant="sidebar"` pane drops its own material, so glass never sits on glass.

## Accessibility

- Each divider is a focusable `separator` with `aria-valuenow`, following the WAI-ARIA window splitter pattern. Name it with `aria-label`, like "Resize mailboxes".
- Arrow keys along the split move the divider, Shift moves it farther, and Home and End go as far as the panes allow.
- Enter, or a double-click, collapses a `collapsible` pane and restores it. A pane collapsed to 0 leaves the tab order and the accessibility tree.

### Data attributes and CSS variables

| Attribute or variable | On | Meaning |
| --- | --- | --- |
| `data-variant` | `.mb-split-view-pane` | `sidebar`, `content` or `inspector` |
| `data-collapsed` | `.mb-split-view-pane` | The pane is collapsed |
| `data-orientation` | every part | `horizontal` or `vertical` |
| `data-dragging` | `.mb-split-view`, `.mb-split-view-divider` | A divider is being dragged |
| `data-hovering` | `.mb-split-view-divider` | The pointer is within the divider's hit area |
| `--resizable-panel-size` | `.mb-split-view-pane` | The pane's share of the group, from ui-sdk |
