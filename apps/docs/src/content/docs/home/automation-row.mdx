# Automation Row

<Lead>List an automation with when it runs, what it does and a switch to turn it off.</Lead>

<Demo name="home/automation-row-basic" platforms={["ios", "ipados", "macos"]} />

## When to use it

Automations make accessories react to a situation: people arriving or leaving, a time of day such as sunset, an accessory being controlled, or a sensor detecting something. The Home app lists them in the Automation tab; pressing one lets people turn it on or off, change when it happens, add or remove accessories, test it or delete it.

- Title the row with the trigger, in the Home app's words: "When I arrive home", "At sunset", "When Back door opens".
- Put what it does in the detail: "Unlock Front door and turn on 3 lights".
- Keep a turned-off automation in the list. Its title and icon step back, and the switch says it's off.

## Usage

```tsx
import { AutomationRow } from "macbetter/automation-row"
import { List, ListSection } from "macbetter/list"
```

Put rows in a `ListSection`. Control the switch with `enabled` and `onEnabledChange`, and open an editor from `onOpen`.

## Platform behavior

The row is a [List](/docs/components/list) row, so it takes the list's metrics: 44-point rows with 17-point text on iOS and iPadOS, and compact rows on macOS. The switch is the platform's switch.

## Accessibility

- The switch is named by the title, so screen readers hear "When I arrive home, switch, on".
- With `onOpen`, the row's body is a button named by the title, sitting under the text; the switch sits above it, so neither is inside the other.
- Space toggles the switch; Enter or Space on the row opens the editor.
