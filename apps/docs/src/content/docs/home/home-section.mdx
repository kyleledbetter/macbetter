# Home Section

## When to use it

The Home tab is a column of sections: Cameras, Scenes, Favorites, then one per room. A room's title links to the room, as the Home app's "Kitchen ›" does, and a line under it can sum up the room.

- Use the room's name as people set it in the Home app. Don't rename it in your app; the HIG asks you to defer to the Home app's settings.
- Keep the summary to the room's conditions: temperature, humidity, how many lights are on.

## Usage

```tsx
import { HomeSection, HomeSectionHeader, HomeSectionSummary, HomeSectionTitle } from "macbetter/home-section"
```

Give `HomeSectionTitle` an `href`, `onClick` or a router link as `render` and it shows a chevron. Name the section with `aria-labelledby` pointing at the title.

### A wallpaper behind the Home tab or a room

The Home app lets people set a wallpaper for each home and each room, and the Home tab and room screens are drawn over it. `HomeBackdrop` paints one behind its children: an abstract Artwork background seeded by the home's or room's name, or a photo from `src`. The wallpaper stays still; make a child the scrolling element so the sections move over it.

```tsx
import { HomeBackdrop } from "macbetter/home-backdrop"

<HomeBackdrop seed="Living Room" variant="wash" palette="dusk" aspect={390 / 844}>
  <NavigationStack>…</NavigationStack>
</HomeBackdrop>
```

<Demo name="home/home-backdrop-room" platforms={["ios", "ipados", "macos"]} />

- Give each home and room its own seed and palette, so switching homes or opening a room changes the mood: `amber` for a kitchen, `dusk` for a living room, `night` for a bedroom, `water` for a bathroom, `slate` for a garage, `forest` for a garden. The [Artwork page](/docs/components/artwork#room-palettes) shows them all.
- `dim` sets how far the wallpaper recedes, from 0 to 1. The default, `0.35`, keeps titles, summaries and translucent tiles above 4.5:1 on the built-in palettes in both schemes. Raise it for a photo or a bright palette. Increase Contrast raises it to at least `0.6`.
- Pass the screen's `aspect`, width over height, so the art is composed for it rather than cropped from a square.

For a room's card or thumbnail, use Artwork directly with the same seed and palette as the room's wallpaper.

## Platform behavior

- **iOS and iPadOS.** 20-point bold titles and 15-point summaries.
- **macOS.** 15-point titles and 12-point summaries.
- **Every platform.** The chevron flips in right-to-left layouts.

## Accessibility

- The title is a real heading, level 2 by default, so people can jump between rooms.
- With `href` it's a link; with `onClick` it's a button inside the heading. Its hit area reaches the platform minimum.

`HomeBackdrop` is a `div`; the wallpaper is a decorative layer behind its children.

| Variable | What it sets |
| --- | --- |
| `--mb-home-backdrop-dim` | The veil's strength, from `dim` |
| `--mb-home-backdrop-dim-min` | The least veil allowed; Increase Contrast sets `0.6` and Reduce Transparency `0.45` |

| Variable | What it sets |
| --- | --- |
| `--mb-home-section-gap` | The space between the header and the content |
| `--mb-home-section-title-font`, `--mb-home-section-summary-font` | The two text styles |
