# Home Section

## When to use it

The Home tab is a column of sections: Cameras, Scenes, Favorites, then one per room. A room's title links to the room, as the Home app's "Kitchen ›" does, and a line under it can sum up the room.

- Use the room's name as people set it in the Home app. Don't rename it in your app; the HIG asks you to defer to the Home app's settings.
- Keep the summary to the room's conditions: temperature, humidity, how many lights are on.

## Usage

```tsx
import { HomeSection, HomeSectionHeader, HomeSectionSummary, HomeSectionTitle } from "macbetter/home-section"
```

Give `HomeSectionTitle` an `href`, `onClick` or a router link as `render` and it shows a chevron. Name the section with `aria-labelledby` pointing at the title.

## Platform behavior

- **iOS and iPadOS.** 20-point bold titles and 15-point summaries.
- **macOS.** 15-point titles and 12-point summaries.
- **Every platform.** The chevron flips in right-to-left layouts.

## Accessibility

- The title is a real heading, level 2 by default, so people can jump between rooms.
- With `href` it's a link; with `onClick` it's a button inside the heading. Its hit area reaches the platform minimum.
