# Thermostat Control

<Lead>Set a thermostat's mode and target temperature on a dial.</Lead>

<Demo name="home/thermostat-control-heat" platforms={["ios", "ipados", "macos"]} wallpaper />

## When to use it

Use it in a thermostat's control sheet. It shows the four things HomeKit's thermostat service holds: the mode (off, heat, cool or auto), the target temperature, the current temperature, and whether the system is heating, cooling or idle.

- In heat and cool, there's one target. In auto, there are two: the heating threshold, below which it heats, and the cooling threshold, above which it cools.
- Say what's happening in words, "Heating to 21°", not only with color.
- Read temperatures in the unit the thermostat or the person uses. HomeKit stores Celsius; `unit="fahrenheit"` converts for display and converts back.

## Usage

```tsx
import { ThermostatControl } from "macbetter/thermostat-control"
```

### Heat and cool

Drag the knob around the dial, or focus it and use the arrow keys. In heat, the dial fills orange from the low end to the target; in cool, blue from the target to the high end. The bar across the track marks the current temperature.

<Demo name="home/thermostat-control-heat" platforms={["ios", "ipados", "macos"]} wallpaper />

### Auto, in Fahrenheit

In auto there are two knobs, and the dial fills between them. They stay at least 3 °F (or 1 °C) apart.

<Demo name="home/thermostat-control-auto" platforms={["ios", "ipados", "macos"]} wallpaper />

## Platform behavior

- **iOS and iPadOS.** A 280-point dial with a 64-point rounded target number.
- **macOS.** A 208-point dial, sized for a popover or a sheet.
- **Every platform.** Off greys out the dial and shows the room's temperature. The mode picker is a segmented control.

## Accessibility

- The dial is drawn, but the control is ui-sdk's Slider: one native range input in heat and cool, named "Heat to" or "Cool to", and two in auto. Pointer drags on the dial set the same slider through its controller, so the value, the keys and what a screen reader announces never disagree.
- The arrow keys step half a degree Celsius or one degree Fahrenheit; Page Up and Page Down step ten. Values read with their unit, like "21.5°C".
- `name` names the whole control, like "Hallway thermostat". The mode picker is named "Mode".
- Heating and cooling show as a colored caption, a colored dot and the words "Heating", "Cooling" or "Idle".

### Data attributes

| Attribute | On | Values |
| --- | --- | --- |
| `data-mode` | Root | `off`, `heat`, `cool`, `auto` |
| `data-state` | Root | `idle`, `heating`, `cooling`; absent when off |
| `data-tone` | Filled arc | `heat`, `cool` |
| `data-thumb` | Knob and thumb | `0`, or `1` for the cooling threshold |
